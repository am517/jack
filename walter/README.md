# Walter — the patrol windup 

Nothing incomplete is forgotten. `walter pending` only lists unfinished work (stage, reason, next return,
UTC; read-only: no patrol, nobody called); `walter patrol` discovers capabilities, wakes what waits for them, and calls Jack with what is due
(`--all` forces everything). No system timers: windups call windups. See `../windups/WINDUPS.md`.
